# Pogo connection concepts

None of the pogo designs is the current keyboard manufacturing candidate. The
production candidate uses the [ribbon-cable universal PCB](../ribbon/universal/).

| Pogo design | Purpose | Status |
|---|---|---|
| [Pogo16 coupon](pogo16-prototype/) | Connector contact and manufacturability coupon | Prototype coupon only |
| [Neo magnetic pogo](neo-archived/) | 12-contact floating spring-head architecture | Archived; do not manufacture |
| [Serpentine pogo](serpentine-archived/) | Earlier target/daughterboard routing experiment | Archived; do not manufacture |

Any future pogo keyboard revision must be rerouted against the current
12-conductor interface and pass connector-coupon, continuity, FFC-motion,
gasket-motion and Hall-noise testing.
