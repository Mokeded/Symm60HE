# Fixed-layout ribbon PCB pairs

Each entry has a left PCB, right PCB, matching split POM plate pair, gasket-pad
pattern and separate Gerber/BOM/CPL package. These boards remove switch,
sensor, LED and alignment features that are not used by that exact layout.

| Friendly name | Repository name | Layout page |
|---|---|---|
| WKL, 2u backspace | `wkl` | [Open](wkl/) |
| WKL + arrows, 2u backspace | `wklarrows` | [Open](wkl-arrows/) |
| WKL, split backspace | `wklbs2` | [Open](wkl-split-backspace/) |
| WKL + arrows + split backspace | `wklbs2arrows` | [Open](wkl-arrows-split-backspace/) |
| WKL left + arrows right, 2u backspace | `wkl-left-arrows-right` | [Open](wkl-left-arrows-right/) |
| Three-key left + WKL right, 2u backspace | `three-key-left-wkl-right` | [Open](three-key-left-wkl-right/) |
| WKL left + arrows right + split backspace | `wkl-left-arrows-right-bs2` | [Open](wkl-left-arrows-right-split-backspace/) |
| Three-key left + WKL right + split backspace | `three-key-left-wkl-right-bs2` | [Open](three-key-left-wkl-right-split-backspace/) |
